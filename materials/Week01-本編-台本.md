# Week 1 本編 — 台本

> **動画概要**: 約 10 分のアニメーション付き解説動画
> **対象**: プログラミング経験ゼロの完全初心者
> **ゴール**: 動画を見終わった瞬間に「私もやってみよう」と PC に向かわせる
> **制作**: HyperFrames (HTML + GSAP) + Irodori-TTS

## 章 1: Claude Code って何? (0:30-2:30 / 6 シーン)

### Scene 1-1 (0:30-0:45) — 章タイトル
**視覚**:
- 「第1章」 (小・ゴールド)
- 「Claude Code って何?」 (大・セリフ体・中央)
- 下線アニメ

**ナレーション**:
> 第一章、クロード・コードって、何でしょうか。

### Scene 1-2 (0:45-1:15) — ChatGPT との違い (1)
**視覚**:
- 左半分「普通の AI」(ChatGPT風アイコン+説明)
- 右半分「クロード・コード」(ターミナル風アイコン+説明)
- それぞれフェードイン

**ナレーション**:
> 普通のAIは、文章で答えてくれます。例えば、「メモ帳アプリの作り方を教えて」と聞くと、手順を文字で説明してくれる。それは、知識豊富な相談相手です。

### Scene 1-3 (1:15-1:45) — ChatGPT との違い (2)
**視覚**:
- 右側のクロード・コードが拡大
- 「実際にやってくれる」と大きく表示
- ファイルアイコンが次々生成されるアニメ

**ナレーション**:
> でも、クロード・コードは、違います。「メモ帳アプリを作って」と頼むと、本当にPCの中に、アプリを作り始める。手を動かしてくれる、優秀な部下です。

### Scene 1-4 (1:45-2:00) — 例えるなら
**視覚**:
- 比較表
  - 普通のAI = 「相談相手」 (人型アイコン)
  - クロード・コード = 「部下」 (ロボット+ハンマー)
- 中央にイコール記号

**ナレーション**:
> 例えるなら、こんな感じです。普通のAIは相談相手、クロード・コードはあなたの部下。

### Scene 1-5 (2:00-2:15) — 何が出来る？
**視覚**:
- 「何が出来るのか?」見出し
- 4 つのアイコン横並び:
  - 📱 アプリ作成
  - 🌐 Web サイト構築
  - 🤖 AI 機能実装
  - 💳 決済導入

**ナレーション**:
> アプリも、ウェブサイトも、エーアイ機能も、決済機能も。日本語で頼むだけで、本当に作れる時代になりました。

### Scene 1-6 (2:15-2:30) — まとめ
**視覚**:
- 「クロード・コード = 日本語で頼むと、PC の中で動く優秀な部下」 (1 行で大きく)
- アンダーライン + ゴールドグロウ

**ナレーション**:
> もう一度、おさらい。クロード・コードは、日本語で頼むと、本当に動いてくれる、あなたの部下です。

## 章 3: インストール (Mac / Windows) (3:45-5:45 / 6 シーン)

### Scene 3-1 (3:45-4:00) — 章タイトル
**視覚**:
- 「第3章」+ 「PC にインストールしよう」
- 4 ステップアイコン (1→2→3→4) 横並び

**ナレーション**:
> 第三章、それでは、あなたのPCに、クロード・コードを入れていきましょう。たった、四ステップです。

### Scene 3-2 (4:00-4:25) — Mac 版手順
**視覚**:
- Mac ロゴ + 「Mac の方」
- ステップ 1: ターミナルを開く (⌘+Space → "ターミナル")
- 黒い画面のスクショ風

**ナレーション**:
> マックの方は、まず、ターミナルを開きます。コマンドキーとスペースキーを同時に押して、「ターミナル」と打って、エンター。これだけです。

### Scene 3-3 (4:25-4:50) — Windows 版手順
**視覚**:
- Windows ロゴ + 「Windows の方」
- ステップ 1: PowerShell を開く (Windowsキー → "PowerShell")
- 青い画面のスクショ風

**ナレーション**:
> ウィンドウズの方は、ウィンドウズキーを押して、「パワーシェル」と打って、エンター。同じようにして、開いてください。

### Scene 3-3b (4:50-5:10) — インストールコマンド
**視覚**:
- ターミナル風の枠の中:
  ```
  $ npm install -g @anthropic-ai/claude-code
  ```
- タイピングアニメーション風 (文字が左から表示)

**ナレーション**:
> 開いた画面に、これをコピーして、ペーストしてください。「エヌピーエム インストール ジー、@アンソロピック・エーアイ・スラッシュ・クロード・コード」。エンターを押すと、自動でインストールが始まります。

### Scene 3-4 (5:10-5:30) — 起動
**視覚**:
- ターミナル風枠:
  ```
  $ claude
  >
  ```
- カーソル点滅アニメ

**ナレーション**:
> 完了したら、「クロード」と打って、エンター。プロンプトと呼ばれる、矢印が表示されたら、成功です。ここに、日本語を打ち込めるようになりました。

### Scene 3-5 (5:30-5:45) — トラブル時
**視覚**:
- 「うまくいかなかったら」 (見出し)
- チェックリスト 3 項目:
  - ✅ ターミナルを再起動
  - ✅ コミュニティに投稿
  - ✅ 30 分以内に解決
**ナレーション**:
> もし、エラーが出ても、安心してください。ターミナルを一度閉じて、もう一度開く。それでも駄目なら、コミュニティに投稿。三十分以内に必ず解決します。

**ナレーション**:
> 三つ目、例を見せる。「ノーションみたいに」「アップルのサイトみたいに」など、参考を示す。ユーアールエルを貼っても、OKです。

### Scene 6-5 (9:08-9:18) — コツ 4
**視覚**:

**ナレーション**:
> 四つ目、修正は、ここを、こうして、と具体的に。「なんか違う」では、ダメ。場所と、変更内容を明確に。

**ナレーション**:

## 制作上のメモ

### 視覚デザイン
- イントロ動画と統一: `#0a0a0f` 黒背景 + `#c9a84c` ゴールドアクセント
- フォント: Noto Serif JP (見出し) + Noto Sans JP (本文・コード)

- 章タイトルは大胆にスライドイン
- 説明箇条書きは Stagger fade-in
- ターミナル表示は文字を 1 文字ずつ表示するタイピング風
- 重要な単語は GSAP の bounce / scale で強調
